## How to Run

Compile and run the desired source from its assignment folder. For example, for Assignment No 1:

```bash
g++ -o assignment1 assignment1.cpp

# Linux / macOS
./assignment1

# Windows
assignment1.exe
```

See each assignment's README for its specific compile and run commands.
